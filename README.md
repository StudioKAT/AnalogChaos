# Analog Chaos

![Analog Chaos_v1.0_Front](<Images/Analog Chaos_v1.0_Front.jpg>)

## 概要 / Overview

**Analog Chaos** は、クラシックなアナログ・カオス回路の系譜を2HPサイズに凝縮した、デュアル・カオスCVジェネレーターです。

上段の **WAVER** は、遅延フィードバックと非線形カーブによって生まれる、波打つようなカオス電圧を出力します。ゆるやかに揺れながらも、単純なLFOとは異なる予測しづらい起伏を持ち、フィルター、VCA、ピッチ、ウェーブフォルダーなどのモジュレーションに有機的な変化を加えます。
出力は **X / Y** の2系統で、互いに関連しながらもわずかに異なる動きをします。

下段の **DRIFT** は、非常にゆっくりとした軌道を描くスローカオスCVソースです。1〜3分程度の周期感を持つ漂うような変化により、パッチ全体の表情を時間をかけて変化させることができます。こちらも **X / Y** の2出力を備え、同じカオス状態から生まれる関連性のある電圧を取り出せます。

**WAVER** はリップルやロールを含む比較的動きのあるカオス、**DRIFT** は長い時間軸でゆっくり移ろうカオスとして設計されています。
どちらもランダム電圧ではなく、アナログ回路のフィードバックから生まれる決定論的な不規則性を持っており、パッチに「偶然のようで、どこか連続性のある」揺らぎを加えることができます。


**Analog Chaos** is a dual analog chaos CV generator, condensed into a compact 2HP Eurorack module and inspired by classic nonlinear feedback circuits.

The upper section, **WAVER**, produces undulating chaotic voltages generated by delayed feedback and a nonlinear transfer stage. It moves with a rippling, rolling character that feels more organic and less predictable than a conventional LFO. It is well suited for modulating filters, VCAs, pitch, wavefolders, and other parameters that benefit from animated, continuously changing CV.
Two related outputs, **X** and **Y**, provide different views of the same chaotic motion.

The lower section, **DRIFT**, is a slow chaos source designed for gradual movement over longer timescales. Based around a slow-orbit topology, it creates drifting CVs with cycles in the range of roughly 1–3 minutes, making it ideal for subtle patch evolution, timbral shifts, and long-form modulation.
Its **X** and **Y** outputs are correlated but not identical, giving two complementary modulation signals from the same chaotic core.

**WAVER** offers a more animated, rippling form of chaos, while **DRIFT** provides slow, evolving motion.
Unlike random voltage sources, both sections are driven by analog feedback behavior, producing modulation that feels unpredictable yet continuous and naturally connected.



## 仕様 / Spec
- Format: Eurorack
- Function: Chaos
- Current needs: +12V: 15mA, -12V: 15mA
- Width: 2 HP
- Depth: 28mm (including power connector)
